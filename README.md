# Yuli – אנגלית לכיתה ד׳

אתר תרגול אנגלית ודיבור לילדים (ממשק בעברית), עם יולי הינשוף:

- 200 מילים בסיסיות (Pre-A1) ב-20 מקבצים, 10 תחנות תרגול לכל מקבץ
- דקדוק ראשון (A1): TO BE, הווה פשוט, ציווי, and/but/or
- תרגול בסגנון מבחן: ניקוד, ch/sh, יוצא דופן, קריאה ושיחה
- כניסה לפי שם משתמש (נשמר בדפדפן בלבד)

## הרצה והפצה
האתר הוא קובץ HTML יחיד (`index.html`) בלי שרת ובלי תלויות. אפשר להעלות אותו לכל אחסון סטטי (Netlify, Cloudflare Pages, GitHub Pages, S3).
זיהוי דיבור עובד ב-Chrome / Edge / Safari בכתובת https.

האתר אינו אתר רשמי של משרד החינוך.
